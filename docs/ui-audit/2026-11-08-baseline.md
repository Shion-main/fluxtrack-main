# UI audit: baseline before the unified responsive UI (2026-11-08)

Measured on a throwaway copy of the dev database (`fluxtrack_journey`, restored
from `fluxtrack`, never the dev DB), with the clock frozen at Monday 2026-07-20
10:52 Manila time so the boards show a live teaching day.

- 61 pages, each at 360, 390, 768, 1024 and 1440 px wide = 305 measurements.
- Per page and width: horizontal overflow (`scrollWidth - clientWidth`), the
  elements that stick out past the right edge (ignoring ones inside a scroll
  container), console errors, and the number of `<header>` elements.
- Tool: `probe.py` in the session scratchpad (gstack browse, one signed-in
  session per role). Screenshots are full-page.
- No page returned a server error (500).

## Other findings

|---|---|---|
